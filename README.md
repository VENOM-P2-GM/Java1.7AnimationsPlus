# Java1.7Animations
This resource pack attempts to faithfully port over many player animations from Minecraft Java Edition v1.7 to Minecraft Bedrock Edition. Contributions are welcome in the form of pull requests! Please submit a detailed issue if you have a bug report.

### About Licensing:
This repository only exists for educational purposes, to aggregate bug reports, and solicit meaningful and quality contributions. If I could distribute an encrypted version of this pack on my own, I would, since theft is rampant in the MCBE mod and pack community. But that isn't possible without a lot of work. Hence, it doesn't seem harmful to "open source" this project. See [LICENSE](https://github.com/ambiennt/Java1.7Animations/blob/main/LICENSE) for exact terms of use.
